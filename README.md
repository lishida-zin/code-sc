# Code-SC: フルスタックエンジニア育成プラットフォーム

> **「動くコードを書く人」から「設計を見抜ける人」へ**
>
> AI時代に求められるシニアエンジニアのスキルを、ゼロから体系的に学べるインタラクティブ教科書

---

## はじめに

### なぜ作ろうと思ったか

2026年、AIがコードを書く時代になりました。GitHub Copilotやclaude Codeが日常的にコードを生成する中で、エンジニアに求められるスキルは大きく変わっています。

**「コードを書ける」だけでは足りない。AIが書いたコードの問題を"見抜ける力"が必要だ。**

この気づきから、このプロジェクトは始まりました。

未経験からエンジニアを目指す中で、巷の教材には大きな課題を感じていました。

- 「写経」中心で、**なぜそう書くのか**が抜け落ちている
- 断片的な知識は増えるが、**全体像が見えない**
- **実務で何を見るべきか**がわからないまま終わる

そこで、自分自身の学習を進めながら、学んだ知識を**そのまま教科書として体系化**するプロジェクトを立ち上げました。単なる学習記録ではなく、**他者にも使える教育プラットフォーム**として設計しています。

### このプロジェクトのゴール

| ゴール | 詳細 |
|--------|------|
| **シニアレベルのコードレビュー力** | AIが生成したコードの脆弱性・設計ミスを指摘できる |
| **フルスタックの知識基盤** | フロント〜バックエンド〜インフラを一人で俯瞰できる |
| **教える力** | 学んだことをPC初心者にも説明できるレベルで理解する |

## 技術的な特徴

### アーキテクチャ

```
textbook/
├── index.html          # SPA エントリポイント（ナビ + ダッシュボード）
├── css/style.css       # WCAG 2.1 AA 準拠スタイル
├── js/main.js          # 動的読み込み・進捗管理・クイズエンジン
└── levelN/phaseM.html  # セクション単位の分割コンテンツ
```

**Vanilla JS による SPA 設計** — フレームワークに依存しない、シンプルで軽量な構成です。

- **動的コンテンツ読み込み**: セクションIDに基づき `fetch()` で対応HTMLを取得・挿入
- **ファイル分割管理**: 各Phase（学習単位）ごとにHTMLファイルを分割し、肥大化を防止
- **クライアントサイド進捗管理**: `localStorage` でセクション完了状態を永続化
- **ハッシュベースルーティング**: URLハッシュ変更を検知し、該当セクションへ自動スクロール

### アクセシビリティ（WCAG 2.1 AA 準拠）

このプロジェクトでは、**LD（学習障害）/ ディスレクシア対応**を重視しています。

| 項目 | 実装内容 |
|------|---------|
| **コントラスト比** | 通常テキスト 12:1 以上（基準 4.5:1 を大幅にクリア） |
| **フォントサイズ** | 本文 20px、h1 32px（一般的なサイトより大きめ） |
| **行間** | 2.0（標準の1.5倍で視認性を確保） |
| **字間** | 0.05em（読みやすさ向上） |
| **背景色** | 真っ白を避けクリーム色（#FEFDFB）を採用し、目の疲労を軽減 |
| **ダークモード** | コントラスト比 15:1 以上を確保した配色 |

### ダークモード対応

CSS カスタムプロパティ（変数）で一元管理し、`data-theme` 属性の切り替えで全体のテーマを変更。

```css
:root {
  --bg-main: #FEFDFB;     /* ライトモード: クリーム色 */
  --text-main: #1F2937;
}

[data-theme="dark"] {
  --bg-main: #0F172A;     /* ダークモード: Slate 900 */
  --text-main: #F1F5F9;
}
```

### インタラクティブ学習機能

- **クイズエンジン**: 全セクションに最低1問以上のクイズを配置。正解/不正解をリアルタイムで判定
- **進捗ダッシュボード**: Level別のプログレスバーで学習の全体像を可視化
- **セクション完了トラッキング**: ボタン押下で完了を記録し、ナビゲーションに反映
- **アコーディオン型ナビゲーション**: Level → Phase → セクションのツリー構造で直感的に操作

## 教育設計のこだわり

### 「なぜ？」を徹底する

```
❌ 「divではなくnavを使いましょう」
⭕ 「セマンティックHTML思想: タグに意味を持たせることで、
    スクリーンリーダーや検索エンジンも内容を理解できるようになる」
```

すべての知識について **WHY（なぜ） → HOW（どうやって） → EFFECT（結果どうなる）** を明示しています。

### 実務直結のコンテンツ

各セクションには以下を必ず含めています。

- **正しいコード例** と **よくある間違い**（AIも犯すミス）
- **レビューで指摘すべきポイント**
- **シニアの思考プロセス**（なぜこの判断をするのか）

### 多角的なクイズ設計

重要トピック（セキュリティ、頻出バグなど）では、1問ではなく複数の角度から出題します。

```
例: XSSに関する3問
  問1（概念）: XSSとは何か？
  問2（発見）: このコードの脆弱性はどこ？
  問3（対策）: 正しい対策コードはどれ？
```

## 使い方

1. リポジトリをクローン
   ```bash
   git clone https://github.com/lishida-zin/code-sc.git
   cd code-sc
   ```

2. 教科書を開く
   ```bash
   open textbook/index.html
   # または、ブラウザで直接 textbook/index.html を開く
   ```

3. ダッシュボードから学習したいLevelを選択

4. セクションを順番に進め、クイズに回答しながら理解を深める
