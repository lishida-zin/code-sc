CSSってなに？

CSSは「Cascading Style Sheets」の略です。

HTMLが「骨組み」なら、CSSは「見た目」を決めます。

💡 かんたんな説明

CSSは「色・大きさ・配置」を決める言語です。

HTMLとCSSの関係

CSSで何ができる？

できること 例
色を変える 文字を赤に、背景を青に
大きさを変える 文字を大きく、画像を小さく
配置を変える 中央揃え、横並び
余白を調整 要素の間隔を広げる

CSSの書き方

セレクタ {
  プロパティ: 値;
}

例：
p {
  color: red;
  font-size: 20px;
}
部分 意味 例
セレクタ どの要素に適用するか p（段落に）
プロパティ 何を変えるか color（色を）
値 どう変えるか red（赤に）

まとめ

✨ 覚えておこう
  1. CSSは見た目を決める言語
  2. HTML（構造）＋ CSS（見た目）＝ Webページ
  3. 「セレクタ { プロパティ: 値; }」の形で書く

9. セレクタ

📚 このページで学ぶこと
  • セレクタの種類
  • 要素・クラス・IDセレクタ
  • 詳細度（どのスタイルが優先されるか）

セレクタ＝「どの要素に適用するか」

セレクタは、CSSをどの要素に適用するかを指定します。

3つの基本セレクタ

種類 書き方 意味
要素セレクタ p { } すべての<p>タグ
クラスセレクタ .box { } class="box"の要素
IDセレクタ #header { } id="header"の要素

要素セレクタ

p {
  color: blue;
}
/* すべての段落が青くなる */

クラスセレクタ（.ドット）

.highlight {
  background: yellow;
}

/* HTML側 */
<p class="highlight">黄色背景</p>

IDセレクタ（#シャープ）

#main-title {
  font-size: 32px;
}

/* HTML側 */
<h1 id="main-title">タイトル</h1>
⚠️ クラスとIDの違い
class id
同じページで 何度でも使える 1回だけ
用途 共通のスタイル 唯一の要素
優先度 低い 高い

詳細度（優先順位）

同じ要素に複数のスタイルがあると、詳細度が高い方が勝ちます。

🏆 優先順位（高い順）
  1. !important（最強、でも使わない方がいい）
  2. IDセレクタ（#header）
  3. クラスセレクタ（.box）
  4. 要素セレクタ（p, div）

まとめ

✨ 覚えておこう
  1. 要素セレクタ：p（タグ名そのまま）
  2. クラスセレクタ：.名前（ドット＋名前）
  3. IDセレクタ：#名前（シャープ＋名前）
  4. 優先度：ID ＞ クラス ＞ 要素

色の指定方法

方法 例 説明

HTMLの要素は、すべて四角い箱です。

13. Flexbox

📚 このページで学ぶこと
  • Flexboxとは
  • 横並び・縦並びの作り方
  • 中央揃えの方法

Flexboxってなに？

Flexboxは、要素を簡単に並べるための仕組みです。

「横並び」「中央揃え」がとても簡単にできます。

基本の使い方

.container {
  display: flex;  /* これだけで横並び！ */
}

display: flex で横並びに

よく使うプロパティ

プロパティ 意味 値の例
justify-content 横方向の揃え center, space-between
align-items 縦方向の揃え center, flex-start
flex-direction 並ぶ方向 row（横）, column（縦）
gap 要素間の隙間 20px, 1rem

中央揃えの魔法

.container {
  display: flex;
  justify-content: center;  /* 横方向：中央 */
  align-items: center;      /* 縦方向：中央 */
}
💡 これだけ覚えれば大丈夫

中央揃えはdisplay: flex + justify-content: center + align-items: center

まとめ

✨ 覚えておこう
  1. display: flexで横並びになる
  2. justify-contentは横方向の揃え
  3. align-itemsは縦方向の揃え
  4. gapで要素間の隙間を作る

14. Grid

📚 このページで学ぶこと
  • CSS Gridとは
  • Flexboxとの違い
  • グリッドレイアウトの作り方

Gridってなに？

Gridは、格子状（グリッド）に要素を並べる仕組みです。

Flexboxは「一列」、Gridは「複数行×複数列」が得意です。

Flexboxは一列、Gridは格子状

基本の使い方

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3列 */
  gap: 20px;                            /* 隙間 */
}
プロパティ 意味 値の例
grid-template-columns 列の幅 1fr 1fr 1fr（3等分）
grid-template-rows 行の高さ 100px auto
gap 隙間 20px
💡 frって何？

frは「fraction（分数）」の略。

1fr 1fr 1frなら「1:1:1で3等分」という意味です。

FlexboxとGridの使い分け

Flexbox Grid
得意なこと 一列に並べる 格子状に並べる
使う場面 ナビ、ボタン並び カード一覧、全体レイアウト

まとめ

✨ 覚えておこう
  1. display: gridで格子状レイアウト
  2. grid-template-columnsで列数を決める
  3. 一列ならFlexbox、格子状ならGrid

15. レスポンシブデザイン基礎

📚 このページで学ぶこと
  • メディアクエリ
  • モバイルファースト
  • Flexbox/Gridの応用

レスポンシブデザインとは

レスポンシブデザインとは、1つのHTMLで様々な画面サイズに対応する手法です。

スマートフォン、タブレット、デスクトップ...どの端末で見ても、見やすいレイアウトになります。

🏠 たとえ話：折りたたみ家具

レスポンシブデザインは「折りたたみ家具」のようなものです。広い部屋では大きく広げて使い、狭い部屋では折りたたんでコンパクトに。空間に合わせて形が変わるのがレスポンシブデザインです。

viewport meta タグ

レスポンシブデザインには、HTMLの<head>に以下のmetaタグが必須です。 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

これがないと、スマートフォンがデスクトップ用のレイアウトを縮小して表示してしまいます。

メディアクエリの書き方

メディアクエリは、画面サイズに応じてCSSを切り替える仕組みです。 

/* 画面幅が768px以下の場合 */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}

/* モバイルファースト：画面幅が768px以上の場合 */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

モバイルファーストアプローチ

モバイルファーストは、まずスマートフォン向けのCSSを書き、min-widthで大きい画面に広げていく考え方です。

💡 なぜモバイルファースト？
  • スマートフォン利用者が過半数を占める
  • シンプルなレイアウトから拡張するほうが設計しやすい
  • パフォーマンスが良い（不要なCSSを読み込まない）

Flexboxでのレスポンシブ実装

flex-wrap: wrap を使うと、画面幅に応じて自動的に折り返されます。 

.card-container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 300px; /* 最小300px、残りを均等に分配 */
}

ブレイクポイントの目安

デバイス 幅の目安 メディアクエリ例
モバイル 〜767px デフォルト（モバイルファースト）
タブレット 768px〜1023px @media (min-width: 768px)
デスクトップ 1024px〜 @media (min-width: 1024px)
❌ 固定幅 
.container {
  width: 960px;
  /* 画面が狭いと横スクロール */
}
⭕ レスポンシブ 
.container {
  max-width: 960px;
  width: 100%;
  /* 画面に合わせて縮む */
}

コード例：レスポンシブカードレイアウト

<div class="card-grid">
  <article class="card">カード1</article>
  <article class="card">カード2</article>
  <article class="card">カード3</article>
</div>

<style>
.card-grid {
  display: grid;
  gap: 20px;
  /* モバイル：1列 */
  grid-template-columns: 1fr;
}

@media (min-width: 768px) {
  .card-grid {
    /* タブレット：2列 */
    grid-template-columns: 1fr 1fr;
  }
}

@media (min-width: 1024px) {
  .card-grid {
    /* デスクトップ：3列 */
    grid-template-columns: 1fr 1fr 1fr;
  }
}
</style>

まとめ

✨ 覚えておこう
  1. レスポンシブデザインは1つのHTMLで複数の画面サイズに対応
  2. viewport meta タグは必須
  3. モバイルファーストで min-width を使って広げていく
  4. flex-wrap や Grid でレスポンシブレイアウトを作る
❓ 確認クイズ
