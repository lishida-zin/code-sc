DevToolsってなに？

DevTools（開発者ツール）は、ブラウザに内蔵された「調査ツール」です。

WebページのHTMLやCSSを見たり、一時的に変更したりできます。

開き方

方法 操作
キーボード F12 または Ctrl+Shift+I（Macは Command+Option+I）
右クリック ページ上で右クリック → 「検証」

Elementsタブ

Elementsタブでは、ページのHTML構造を見ることができます。

🔍 できること
  • HTMLの構造を確認
  • 要素にどのCSSが適用されているか確認
  • CSSを一時的に変更して試す

要素を検証する手順

  1. DevToolsを開く
  2. 左上の「矢印アイコン」をクリック
  3. ページ上の調べたい要素をクリック
  4. 右側にCSSが表示される
⚠️ 注意点

DevToolsでの変更は一時的です。

ページをリロードすると元に戻ります。

まとめ

✨ 覚えておこう
  1. F12でDevToolsを開く
  2. ElementsタブでHTML/CSSを確認
  3. CSSを一時的に変更して試せる

16. 実サイト読解

📚 このページで学ぶこと
  • 実際のWebサイトのコードを読む方法
  • 構造を把握するコツ
  • シニアエンジニアの読み方

なぜ実サイトを読むのか？

教科書で学んだことを、実際のコードで確認することが大切です。

プロが書いたコードには、良いパターンがたくさんあります。

読み方の手順

  1. 全体構造を把握する（header, main, footer）
  2. セマンティックタグを確認する（nav, article など）
  3. クラス名から意図を読み取る
  4. CSSでどうスタイルが当たっているか確認

シニアエンジニアの読み方

👀 見るポイント
  • 「このレイアウトはFlexbox？Grid？」
  • 「クラス名の命名規則は何？」
  • 「セマンティックタグは適切に使われている？」
  • 「アクセシビリティは考慮されている？」

練習方法

  1. 好きなWebサイトを開く
  2. DevToolsを開く（F12）
  3. header, nav, main, footer を探す
  4. Flexbox/Gridがどこで使われているか確認

まとめ

✨ 覚えておこう
  1. 実サイトのコードを読む練習をする
  2. 全体構造から把握する
  3. クラス名から意図を読み取る

17. UIパターン認識

📚 このページで学ぶこと
  • よくあるUIパターン
  • パターンの名前と構造
  • 見た瞬間にわかるようになる

UIパターンを知る意味

Webサイトには「よくある形」があります。

パターンを知っていると、コードを見た瞬間に「これはカードだな」とわかります。

代表的なUIパターン

パターン名 特徴 よくある場所
ヘッダー ロゴ、ナビ、検索 ページ上部
ナビゲーション リンクの並び ヘッダー内、サイドバー
カード 画像＋タイトル＋説明 商品一覧、記事一覧
フォーム 入力欄＋ボタン ログイン、検索
フッター 著作権、リンク集 ページ下部

カードパターンの例

<article class="card">
  <img src="thumbnail.jpg" alt="...">
  <h3>記事タイトル</h3>
  <p>記事の説明文...</p>
  <a href="...">もっと読む</a>
</article>
💡 見分けるコツ
  • クラス名にcardが含まれる
  • articleタグで囲まれている
  • Gridで複数並んでいる

まとめ

✨ 覚えておこう
  1. UIにはよくあるパターンがある
  2. パターン名を知っているとコードが読みやすくなる
  3. ヘッダー、ナビ、カード、フォーム、フッターが基本

18. 2026年のCSS新機能

📚 このページで学ぶこと
  • CSS変数
  • :has()セレクタ
  • Container Queries

知っておくべき新機能

CSSは進化し続けています。

最新の機能を知っておくと、モダンなコードが読めるようになります。

CSS変数（カスタムプロパティ）

色やサイズを変数として定義できます。 

:root {
  --primary-color: #2563EB;
  --spacing: 20px;
}

.button {
  background: var(--primary-color);
  padding: var(--spacing);
}
💡 メリット
  • 色を一箇所で管理できる
  • テーマ切り替えが簡単
  • コードの意味がわかりやすい

:has()セレクタ

「子要素を持つ親」を選べる、革命的なセレクタです。 

/* 画像を持つカードだけ背景色を変える */
.card:has(img) {
  background: #f0f0f0;
}

Container Queries

画面サイズではなく、コンテナのサイズに応じてスタイルを変えます。 

.card-container {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .card {
    flex-direction: row;
  }
}

まとめ

✨ 覚えておこう
  1. CSS変数で色やサイズを一元管理
  2. :has()で子要素を条件に親を選択
  3. Container Queriesでコンポーネント単位のレスポンシブ
📖 今は「読めればOK」

これらの機能は、コードで見かけたときに「何をしているか」わかればOKです。

実際に使うのは、もっと慣れてからで大丈夫。
