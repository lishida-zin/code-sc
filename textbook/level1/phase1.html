HTMLって何だろう？

HTMLは「HyperText Markup Language」の略です。

難しく聞こえますが、簡単に言うと：

💡 かんたんな説明

HTMLは「Webページの骨組み」を作る言語です。

たとえ話：家を建てること

Webページを「家」に例えてみましょう。

HTMLは骨組み、CSSは見た目

役割 家で言うと Webで言うと
HTML 骨組み・柱・壁の位置 文字・画像・ボタンの配置
CSS 壁紙・家具・色 色・大きさ・フォント
JavaScript 電気・水道・動くもの クリック・アニメーション

なぜHTMLが必要なの？

ブラウザ（ChromeやSafari）は、HTMLを読んで画面を表示します。

HTMLがないと、ブラウザは「何を表示すればいいか」わかりません。

❌ HTMLなし

ただの文字の羅列

これは見出しこれは本文これはリンク

⭕ HTMLあり

これは見出し

これは本文

これはリンク

HTMLの正体：「タグ」で囲む

HTMLでは、「タグ」という印で文字を囲みます。 

<h1>これは見出し</h1>
<p>これは本文</p>
<a href="...">これはリンク</a>

タグがあることで、ブラウザは「これは見出しだな」「これはリンクだな」と理解します。

🔤 用語の意味
  • h1 = heading 1（見出し1）
  • p = paragraph（段落）
  • a = anchor（リンクのこと）

まとめ

✨ 覚えておこう
  1. HTMLはWebページの骨組みを作る言語
  2. タグで文字を囲んで、意味を伝える
  3. HTMLが構造、CSSが見た目、JavaScriptが動き

2. タグの基本

📚 このページで学ぶこと
  • タグの形（開始タグ・終了タグ）
  • 属性ってなに？
  • よくある間違いと直し方

タグの基本形

HTMLのタグは、「箱」のようなものです。

箱を開けて、中身を入れて、閉じる。

タグは「開始」「内容」「終了」の3つでできている

<p>これは段落です</p>

↑開始タグ  ↑内容   ↑終了タグ
💡 ポイント

終了タグにはスラッシュ（/）がついています。

<p> → </p>

属性：追加の情報を与える

属性は、タグに「追加の説明」を与えます。

たとえば「どこにリンクするか」「画像のファイル名は何か」など。 

<a href="https://google.com">Googleへ</a>

   ↑属性名  ↑属性値
🔤 属性のルール
  • 属性は開始タグの中に書く
  • 属性名は小文字で書く
  • 属性値はダブルクォート（"）で囲む

空要素：閉じタグがいらないタグ

一部のタグは、中身を持たないので終了タグが不要です。

タグ 意味 使い方
<br> 改行 ここで改行<br>次の行
<hr> 水平線 区切りを入れる
<img> 画像 <img src="photo.jpg">
<input> 入力欄 フォームの入力欄

よくある間違い

❌ 間違い

終了タグ忘れ

<p>段落1
<p>段落2
⭕ 正しい

ちゃんと閉じる

<p>段落1</p>
<p>段落2</p>
❌ 間違い

入れ子が崩れている

<p><strong>太字</p></strong>
⭕ 正しい

開いた順の逆で閉じる

<p><strong>太字</strong></p>
📝 覚え方

「先に開けたら、後に閉じる」

お弁当箱と同じ。大きい箱の中に小さい箱を入れたら、小さい箱から先に閉じる。

まとめ

✨ 覚えておこう
  1. タグは開始タグ・内容・終了タグの3つでできている
  2. 属性で追加の情報を与える（href、srcなど）
  3. 入れ子は「開いた順の逆で閉じる」
❓ 確認クイズ

次のコードの問題点は？

<p><a href="test.html">リンク</p></a>

3. 文書構造

📚 このページで学ぶこと
  • HTMLファイルの基本形
  • head と body の違い
  • 必ず書くもの

HTMLファイルの全体像

すべてのHTMLファイルは、同じ「形」を持っています。

HTMLファイルの構造

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>ページタイトル</title>
</head>
<body>
  ここに表示する内容
</body>
</html>

各部分の役割

DOCTYPE宣言

<!DOCTYPE html> は「これはHTML5です」という宣言。

必ず1行目に書く。これがないと、古いモードで表示される。

head：見えない情報

<head>の中には、ユーザーに見えない設定を書きます。

タグ 役割
<meta charset="UTF-8"> 日本語を正しく表示する
<title> ブラウザのタブに表示
<link> CSSファイルを読み込む

body：見える内容

<body>の中には、ユーザーに見える内容を書きます。

文字、画像、ボタン、リンク...全部ここに入れます。

⚠️ よくある間違い
  • <title>をbodyに書く → タブに表示されない
  • charsetを書き忘れる → 文字化けする

まとめ

✨ 覚えておこう
  1. DOCTYPEは1行目に必ず書く
  2. headは見えない設定（title、charsetなど）
  3. bodyは見える内容（文字、画像など）
❓ 確認クイズ

4. テキスト要素

📚 このページで学ぶこと
  • 見出し（h1〜h6）の使い方
  • 段落（p）と改行（br）の違い
  • 強調（strong、em）

見出し：h1〜h6

見出しはh1からh6まであります。

数字が小さいほど重要です。

見出しの大きさと重要度

⚠️ 大事なルール
  • h1は1ページに1つだけ（ページのタイトル）
  • 順番を飛ばさない（h1→h3はNG、h1→h2→h3はOK）

段落と改行

タグ 意味 使い方
<p> 段落（paragraph） 意味のまとまりごとに使う
<br> 改行（break） 同じ段落内で行を変える
❌ 悪い例

改行のためにbrを連発

文章1<br><br><br>文章2
⭕ 良い例

意味ごとにpタグで分ける

<p>文章1</p>
<p>文章2</p>

強調：strong と em

タグ 意味 見た目
<strong> 重要（strong = 強い） 太字
<em> 強調（emphasis = 強調） 斜体
💡 ポイント

見た目を変えたいだけならCSSを使う。

「意味として重要」なときだけstrongやemを使う。

まとめ

✨ 覚えておこう
  1. 見出しはh1が最重要、数字が大きいほど小さい見出し
  2. h1は1ページに1つ、順番は飛ばさない
  3. 段落はp、改行はbr（使いすぎ注意）
❓ 確認クイズ

5. リンク・画像

📚 このページで学ぶこと
  • リンク（aタグ）の書き方
  • 画像（imgタグ）の書き方
  • alt属性の重要性

リンク：aタグ

aはanchor（アンカー＝錨）の略。

他のページに「つなぐ」役割です。 

<a href="https://google.com">Googleへ</a>
属性 意味 例
href リンク先のURL "https://google.com"
target 開き方 "_blank"（新しいタブ）

画像：imgタグ

imgはimage（画像）の略。

終了タグは不要です（空要素）。 

<img src="photo.jpg" alt="写真の説明">
属性 意味 必須？
src 画像ファイルの場所 必須
alt 画像の説明文 必須
width 横幅 任意
height 高さ 任意

alt属性がなぜ重要？

🔴 alt属性がないと...
  • 目が見えない人が画像の内容を理解できない
  • 画像が読み込めなかったとき、何の画像かわからない
  • 検索エンジンが画像を理解できない
❌ ダメな例 
<img src="cat.jpg">

altがない！

⭕ 良い例 
<img src="cat.jpg" alt="ソファで眠る茶色の猫">

内容がわかる説明

まとめ

✨ 覚えておこう
  1. リンクは<a href="...">で作る
  2. 画像は<img src="..." alt="...">で表示
  3. alt属性は必須（アクセシビリティのため）
❓ 確認クイズ

6. リスト

📚 このページで学ぶこと
  • 順序なしリスト（ul）
  • 順序ありリスト（ol）
  • リストの入れ子

2種類のリスト

タグ 名前 使う場面 見た目
<ul> Unordered List（順序なし） 順番が関係ない項目 ・で表示
<ol> Ordered List（順序あり） 順番が大事な項目 1. 2. 3. で表示
<li> List Item（項目） リストの各項目 -

書き方

📋 順序なしリスト 
<ul>
  <li>りんご</li>
  <li>みかん</li>
  <li>バナナ</li>
</ul>

結果：

  • りんご
  • みかん
  • バナナ
🔢 順序ありリスト 
<ol>
  <li>材料を準備</li>
  <li>混ぜる</li>
  <li>焼く</li>
</ol>

結果：

  1. 材料を準備
  2. 混ぜる
  3. 焼く
⚠️ よくある間違い

liタグだけ書いてul/olを書き忘れる

❌ <li>項目1</li><li>項目2</li>
⭕ <ul><li>項目1</li><li>項目2</li></ul>

まとめ

✨ 覚えておこう
  1. ulは順序なし（・で表示）
  2. olは順序あり（1.2.3.で表示）
  3. 項目はliタグで書く
  4. ul/olの中にliを入れる（liだけはNG）
❓ 確認クイズ

7. セマンティックHTML

📚 このページで学ぶこと
  • セマンティック（意味のある）タグとは
  • header, nav, main, footer などの使い方
  • なぜdivだけではダメなのか

セマンティックって何？

セマンティックは「意味のある」という意味です。

タグを見ただけで「ここは何の役割か」がわかるようにします。

divだらけ vs セマンティックタグ

主なセマンティックタグ

タグ 意味 使う場所
<header> ヘッダー（頭） ページ上部、ロゴやタイトル
<nav> ナビゲーション メニュー、リンク集
<main> メインコンテンツ ページの主要な内容
<article> 記事 独立したコンテンツ
<section> セクション 章、区切り
<aside> 補足情報 サイドバー、関連リンク
<footer> フッター（足） ページ下部、著作権情報

なぜセマンティックが大事？

💡 3つの理由
  1. アクセシビリティ：スクリーンリーダーが「ここはナビゲーション」と読み上げられる
  2. SEO：Googleが「ここがメインコンテンツ」と理解できる
  3. 保守性：開発者がコードを見てすぐ構造がわかる

まとめ

✨ 覚えておこう
  1. セマンティック＝「意味のある」タグを使う
  2. divだけでなく、header, nav, main, footer を使い分ける
  3. アクセシビリティ、SEO、保守性が向上する
