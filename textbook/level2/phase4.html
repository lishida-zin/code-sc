24. 分割代入

🎯 このレッスンで読めるようになること
  • オブジェクトの分割代入を読める
  • 配列の分割代入を読める
  • デフォルト値、リネームを理解できる

分割代入とは？

分割代入（Destructuring）は、
オブジェクトや配列から値を取り出す便利な書き方です。

📦 たとえ話：箱から中身を取り出す

箱（オブジェクト）の中にある物を、
一度に複数取り出して名前を付けるイメージです。

オブジェクトの分割代入

❌ 従来の書き方
const user = { name: '太郎', age: 25 };

const name = user.name;
const age = user.age;
⭕ 分割代入
const user = { name: '太郎', age: 25 };

const { name, age } = user;
// name → '太郎'
// age  → 25
⚠️ 重要：変数名 = プロパティ名

{ name }と書くと、user.nameの値が
同じ名前の変数nameに入ります。

配列の分割代入

const colors = ['赤', '青', '緑'];

const [first, second, third] = colors;
// first  → '赤'
// second → '青'
// third  → '緑'
💡 配列は順番で取り出す

オブジェクト → 名前で取り出す
配列 → 順番で取り出す

デフォルト値

const user = { name: '太郎' };

// ageがない場合、20がデフォルト
const { name, age = 20 } = user;
// name → '太郎'
// age  → 20（デフォルト値）

リネーム（別名を付ける）

const user = { name: '太郎', age: 25 };

// nameをuserNameという変数に入れる
const { name: userName, age: userAge } = user;
// userName → '太郎'
// userAge  → 25
⚠️ 読み方に注意

name: userNameは
「nameをuserNameとして取り出す」という意味です。

ネスト（入れ子）の分割代入

const user = {
  name: '太郎',
  address: {
    city: '東京',
    zip: '100-0001'
  }
};

// addressの中のcityを取り出す
const { address: { city } } = user;
// city → '東京'

関数の引数で使う

実務で最も多い使い方です。
Reactなどで頻繁に見かけます。 

// ❌ 従来の書き方
function greet(user) {
  console.log(`こんにちは、${user.name}さん`);
}

// ⭕ 分割代入を使う
function greet({ name, age }) {
  console.log(`こんにちは、${name}さん（${age}歳）`);
}

greet({ name: '太郎', age: 25 });
// → 'こんにちは、太郎さん（25歳）'

クイズ1：この分割代入でxの値は？ 

const obj = { a: 1, b: 2, c: 3 };
const { b: x } = obj;
解説：{ b: x }は「bをxとして取り出す」という意味。 obj.bの値2がxに入ります。

クイズ2：配列の分割代入でsecondの値は？ 

const [first, second] = [10, 20, 30];
解説：配列の分割代入は順番で取り出します。 firstに10、secondに20が入ります。 30は取り出されません。
📝 まとめ
  • オブジェクト → { name }で名前を指定して取り出す
  • 配列 → [a, b]で順番に取り出す
  • デフォルト値 → { name = '名無し' }
  • リネーム → { name: userName }
  • 関数の引数で使うパターンが最も多い

25. スプレッド構文

🎯 このレッスンで読めるようになること
  • スプレッド構文（...）の使い方を理解
  • 配列・オブジェクトのコピーを読める
  • レスト構文との違いがわかる

スプレッド構文とは？

スプレッド構文（Spread Syntax）は、
...（ドット3つ）で配列やオブジェクトを展開します。

🎴 たとえ話：トランプを広げる

トランプの束（配列）をテーブルに広げるイメージ。
1枚ずつバラバラに展開されます。

配列のスプレッド

const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

// 配列を結合
const combined = [...arr1, ...arr2];
// → [1, 2, 3, 4, 5, 6]

// 配列をコピー
const copy = [...arr1];
// → [1, 2, 3]（別の配列）
⚠️ 重要：シャローコピー（浅いコピー）

スプレッド構文は1階層目だけコピーします。
ネストしたオブジェクトは参照が共有されます。

オブジェクトのスプレッド

const user = { name: '太郎', age: 25 };

// オブジェクトをコピー
const copy = { ...user };
// → { name: '太郎', age: 25 }（別のオブジェクト）

// プロパティを追加・上書き
const updated = { ...user, age: 26, city: '東京' };
// → { name: '太郎', age: 26, city: '東京' }
🔴 実務超重要：イミュータブル更新

Reactなどで状態を更新するとき、
元のオブジェクトを変更せず、新しいオブジェクトを作るのが鉄則。
スプレッド構文はそのための必須テクニックです。

❌ 直接変更（ミュータブル）
const user = { name: '太郎', age: 25 };

// 元のオブジェクトを変更
user.age = 26;  // ← 危険！
⭕ 新しく作る（イミュータブル）
const user = { name: '太郎', age: 25 };

// 新しいオブジェクトを作成
const updated = { ...user, age: 26 };

レスト構文（残り全部）

同じ...でも、残りをまとめる使い方もあります。 

// 配列の残り
const [first, ...rest] = [1, 2, 3, 4, 5];
// first → 1
// rest  → [2, 3, 4, 5]

// オブジェクトの残り
const { name, ...others } = { name: '太郎', age: 25, city: '東京' };
// name   → '太郎'
// others → { age: 25, city: '東京' }
💡 スプレッド vs レスト
名前 位置 意味
スプレッド 右辺 展開する
レスト 左辺 残りをまとめる

関数の引数で使う

function sum(a, b, c) {
  return a + b + c;
}

const numbers = [1, 2, 3];

// 配列を展開して引数に渡す
sum(...numbers);  // → 6
// sum(1, 2, 3) と同じ

クイズ1：このresultの値は？ 

const a = [1, 2];
const b = [3, 4];
const result = [...a, ...b];
解説：スプレッド構文は配列を展開するので、 [...a, ...b]は[1, 2, 3, 4]になります。

クイズ2：このupdatedのageは？ 

const user = { name: '太郎', age: 25 };
const updated = { ...user, age: 30 };
解説：後から指定したプロパティで上書きされます。 ...userでage: 25が入った後、 age: 30で上書きされます。
📝 まとめ
  • ...で配列・オブジェクトを展開
  • コピー → [...arr] / { ...obj }
  • 結合 → [...arr1, ...arr2]
  • 上書き → { ...obj, key: newValue }
  • シャローコピー（1階層のみ）に注意

レビューで指摘すべきポイント

🔴 よくある問題
問題 指摘例
オブジェクトの直接変更 「スプレッド構文でコピーしてから更新すべき」
ネストの深いオブジェクトでスプレッド 「シャローコピーなので内部オブジェクトは共有される」

26. テンプレートリテラル

🎯 このレッスンで読めるようになること
  • バッククォート文字列を読める
  • 変数の埋め込み（${}）を理解
  • 複数行文字列を読める

テンプレートリテラルとは？

テンプレートリテラルは、
バッククォート（`）で囲む文字列です。

⌨️ バッククォートの位置

キーボードの左上、Shiftキー + @で入力。
シングルクォート（'）やダブルクォート（"）とは違います。

変数の埋め込み

❌ 従来の書き方（文字列結合）
const name = '太郎';
const age = 25;

const msg = 'こんにちは、' + name + 'さん（' + age + '歳）';
⭕ テンプレートリテラル
const name = '太郎';
const age = 25;

const msg = `こんにちは、${name}さん（${age}歳）`;
⚠️ 重要：${ }の中に式が書ける

${ }の中には変数だけでなく、
計算式や関数呼び出しも書けます。 

const price = 1000;
const tax = 0.1;

// 計算式を埋め込み
const msg = `税込価格: ${price * (1 + tax)}円`;
// → '税込価格: 1100円'

// 関数呼び出しを埋め込み
const name = 'taro';
const greeting = `こんにちは、${name.toUpperCase()}さん`;
// → 'こんにちは、TAROさん'

複数行の文字列

❌ 従来の書き方
const html = '
\n' +
  '  
Hello
\n' +
  '
';
⭕ テンプレートリテラル
const html = `

  
Hello


`;
💡 改行がそのまま入る

バッククォート内の改行は、
そのまま改行文字として扱われます。

実務での使用例

// APIエンドポイントの構築
const userId = 123;
const url = `https://api.example.com/users/${userId}/profile`;

// エラーメッセージ
const error = new Error(`ユーザーID ${userId} が見つかりません`);

// HTML生成（注意：XSS対策が必要）
const items = ['りんご', 'みかん', 'ぶどう'];
const html = `
    
  ${items.map(item => `
  • ${item}
    • `).join('')}

`;

クイズ1：このresultの値は？ 

const a = 5;
const b = 3;
const result = `${a} + ${b} = ${a + b}`;
解説：${ }内は評価されて値に置き換わります。 ${a}は5、${b}は3、${a + b}は8になります。

クイズ2：次のうち、正しいテンプレートリテラルは？

解説：テンプレートリテラルはバッククォート（`）で囲みます。 シングルクォートやダブルクォートでは${ }が文字列として扱われます。
📝 まとめ
  • バッククォート（`）で囲む
  • ${変数}で値を埋め込む
  • ${式}で計算結果を埋め込む
  • 改行がそのまま入る
  • 文字列結合より読みやすい

27. モジュール

🎯 このレッスンで読めるようになること
  • import/exportの基本を読める
  • 名前付きエクスポートとデフォルトエクスポートの違い
  • モジュールの利点を理解

モジュールとは？

モジュールは、
コードをファイル単位で分割・再利用する仕組みです。

🧩 たとえ話：レゴブロック

各モジュール = 1つのレゴブロック
組み合わせて大きなものを作ります。

なぜモジュールが必要？

❌ 1ファイルに全部
// app.js（1000行）
// ユーザー関連の関数
// 商品関連の関数
// カート関連の関数
// 決済関連の関数
// ...全部ここに
⭕ モジュール分割
// user.js
// product.js
// cart.js
// payment.js
// app.js（メイン）

名前付きエクスポート

// math.js
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export function multiply(a, b) {
  return a * b;
}
// 使う側（main.js）
import { PI, add, multiply } from './math.js';

console.log(PI);          // 3.14159
console.log(add(1, 2));   // 3
⚠️ 重要：{ }で囲む

名前付きエクスポートをインポートするときは、
{ }で囲む必要があります。
名前はエクスポート時と同じにします。

デフォルトエクスポート

// User.js
export default class User {
  constructor(name) {
    this.name = name;
  }
}
// 使う側（main.js）
import User from './User.js';  // { }不要

const user = new User('太郎');
💡 名前付き vs デフォルト
種類 エクスポート インポート 用途
名前付き export const x { x } 複数の関数・定数
デフォルト export default X（{ }なし） メインのクラス・関数

混在パターン

// api.js
export const API_URL = 'https://api.example.com';

export function get(path) {
  return fetch(API_URL + path);
}

export default {
  get,
  API_URL
};
// 使う側
// 方法1: 名前付きでインポート
import { API_URL, get } from './api.js';

// 方法2: デフォルトでインポート
import api from './api.js';
api.get('/users');

リネーム（as）

// 名前が衝突するときに使う
import { add as mathAdd } from './math.js';
import { add as stringAdd } from './string.js';

mathAdd(1, 2);     // 数値の加算
stringAdd('a', 'b'); // 文字列の結合

全部インポート（*）

// すべてを1つのオブジェクトとしてインポート
import * as math from './math.js';

math.PI;           // 3.14159
math.add(1, 2);    // 3

クイズ1：名前付きエクスポートをインポートする正しい書き方は？

解説：名前付きエクスポートは{ }で囲みます。 { }なしはデフォルトエクスポート用です。

クイズ2：デフォルトエクスポートの特徴は？

解説：デフォルトエクスポートは1ファイルに1つだけです。 名前付きエクスポートは複数作れます。
📝 まとめ
  • exportで公開、importで読み込み
  • 名前付き → { }で囲む
  • デフォルト → { }不要、1ファイル1つ
  • asでリネーム可能
  • コードを分割して保守性を上げる

28. クラス

🎯 このレッスンで読めるようになること
  • class構文の基本を読める
  • constructor, メソッドを理解
  • 継承（extends）を読める

クラスとは？

クラスは、
オブジェクトの設計図です。

🏭 たとえ話：たい焼きの型

クラス = たい焼きの型（設計図）
インスタンス = 焼かれたたい焼き（実体）
1つの型から何個でも作れます。

基本的なクラス

class User {
  // コンストラクタ（初期化処理）
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // メソッド
  greet() {
    return `こんにちは、${this.name}です`;
  }
}

// インスタンス作成
const taro = new User('太郎', 25);
console.log(taro.name);    // '太郎'
console.log(taro.greet()); // 'こんにちは、太郎です'
⚠️ 重要：newを付ける

クラスからインスタンスを作るときは、
必ずnewを付けます。
付けないとエラーになります。

継承（extends）

// 親クラス
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    return `${this.name}が鳴きます`;
  }
}

// 子クラス（Animalを継承）
class Dog extends Animal {
  speak() {
    return `${this.name}がワンワン！`;
  }
}

const dog = new Dog('ポチ');
console.log(dog.speak()); // 'ポチがワンワン！'

super（親を呼ぶ）

class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // 親のconstructorを呼ぶ（必須！）
    this.breed = breed;
  }
}

const dog = new Dog('ポチ', '柴犬');
console.log(dog.name);  // 'ポチ'
console.log(dog.breed); // '柴犬'
🔴 superは最初に呼ぶ

子クラスのconstructorでthisを使う前に、
必ずsuper()を呼ぶ必要があります。

getter / setter

class Circle {
  constructor(radius) {
    this._radius = radius;
  }

  // getter（取得時に呼ばれる）
  get area() {
    return Math.PI * this._radius ** 2;
  }

  // setter（設定時に呼ばれる）
  set radius(value) {
    if (value <= 0) throw new Error('正の値を指定');
    this._radius = value;
  }
}

const circle = new Circle(5);
console.log(circle.area);   // 78.54...（関数呼び出しなし）
circle.radius = 10;         // setterが呼ばれる

static（静的メソッド）

class MathUtil {
  static add(a, b) {
    return a + b;
  }
}

// インスタンス不要で呼べる
MathUtil.add(1, 2);  // 3

クイズ1：クラスからインスタンスを作る正しい方法は？

解説：クラスからインスタンスを作るにはnewが必要です。 newなしで呼ぶとエラーになります。

クイズ2：子クラスのconstructorで必ず最初にすることは？

解説：extendsで継承したクラスのconstructorでは、 thisを使う前にsuper()で親のconstructorを呼ぶ必要があります。
📝 まとめ
  • classはオブジェクトの設計図
  • constructorで初期化
  • newでインスタンス作成
  • extendsで継承、superで親を呼ぶ
  • staticはインスタンス不要で呼べる

レビューで指摘すべきポイント

🔴 よくある問題
問題 指摘例
不要なクラス 「1つのメソッドなら関数で十分」
super()忘れ 「継承時はsuper()が必須」

29. クロージャ

⭐ 面接頻出トピック

クロージャは技術面接でほぼ確実に聞かれます。
しっかり理解しておきましょう。

🎯 このレッスンで読めるようになること
  • クロージャの概念を理解
  • クロージャを使ったコードを読める
  • 実用的なパターンを把握

クロージャとは？

クロージャは、
外側の変数を「覚えている」関数です。

🎒 たとえ話：リュックを背負った関数

関数が「リュック」を背負っていて、
その中に外側の変数を持ち歩いているイメージ。
関数がどこに行っても、リュックの中身（変数）にアクセスできます。

基本的な例

function createCounter() {
  let count = 0;  // この変数が「閉じ込められる」

  return function() {
    count++;
    return count;
  };
}

const counter = createCounter();

console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3
⚠️ 重要ポイント
  • countはcreateCounterの中で定義
  • createCounter()の実行が終わってもcountは消えない
  • 返された関数がcountを「覚えている」

なぜ変数が消えない？

// 通常、関数が終わると変数は消える
function normal() {
  let x = 10;
  return x;
}
// normal()が終わると、xは消える

// クロージャでは消えない
function createClosure() {
  let x = 10;
  return function() {
    return x;  // xを参照している
  };
}
const fn = createClosure();
// createClosure()は終わったが、
// fn()がxを参照しているので、xは残る
💡 ガベージコレクション

JavaScriptは「誰も使わない変数」を自動で削除します。
クロージャで参照されている変数は「使われている」ので消えないのです。

実用例1：プライベート変数

function createBankAccount(initial) {
  let balance = initial;  // 外からアクセス不可

  return {
    deposit(amount) {
      balance += amount;
      return balance;
    },
    withdraw(amount) {
      if (amount > balance) {
        throw new Error('残高不足');
      }
      balance -= amount;
      return balance;
    },
    getBalance() {
      return balance;
    }
  };
}

const account = createBankAccount(1000);
account.deposit(500);   // 1500
account.withdraw(200);  // 1300
account.balance;        // undefined（アクセスできない！）

実用例2：カリー化

function multiply(a) {
  return function(b) {
    return a * b;
  };
}

const double = multiply(2);
const triple = multiply(3);

double(5);  // 10
triple(5);  // 15

面接でよく聞かれる問題

🔴 有名な罠：ループとクロージャ

このコードの出力は？

// ❌ よくある間違い（var使用）
for (var i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i);
  }, 1000);
}
// 期待: 0, 1, 2
// 実際: 3, 3, 3（！）

理由：varはブロックスコープを持たないため、
すべてのsetTimeoutが同じi（最終値3）を参照します。 

// ⭕ 解決策1: letを使う（推奨）
for (let i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i);
  }, 1000);
}
// 出力: 0, 1, 2

// ⭕ 解決策2: クロージャで値を閉じ込める
for (var i = 0; i < 3; i++) {
  (function(j) {
    setTimeout(function() {
      console.log(j);
    }, 1000);
  })(i);
}
// 出力: 0, 1, 2

クイズ1：クロージャとは何ですか？

解説：クロージャは、関数が定義された時点のスコープ（変数環境）を覚えている関数です。 外側の関数が終了しても、その変数にアクセスできます。

クイズ2：このcounter()を3回呼んだ結果は？ 

function createCounter() {
  let count = 0;
  return function() {
    return ++count;
  };
}
const counter = createCounter();
counter(); counter(); counter();
解説：クロージャによりcountが保持されます。 呼び出すたびにインクリメントされるので、1, 2, 3となります。

クイズ3：このコードの出力は？（1秒後） 

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 1000);
}
解説：varはブロックスコープを持たないため、 すべてのsetTimeoutが同じiを参照します。 ループ終了時にiは3なので、3が3回出力されます。 letを使えば0, 1, 2になります。
📝 まとめ
  • クロージャ = 外側の変数を覚えている関数
  • プライベート変数の実現に使える
  • ループ + var + 非同期は罠（letを使う）
  • 面接頻出：必ず理解しておく

30. this

⭐ 面接頻出 & つまずきポイント

thisはJavaScript最大の難関の一つ。
「何を指すかは呼び出し方で変わる」のがポイントです。

🎯 このレッスンで読めるようになること
  • thisの基本ルールを理解
  • 呼び出し方による違いを把握
  • アロー関数のthisを理解

thisとは？

thisは、
「今、この関数を呼び出しているもの」を指します。

👆 たとえ話：「私」という代名詞

「私」が誰を指すかは、誰が話しているかで変わる。
thisも同じで、どう呼び出されたかで変わります。

thisの4つのパターン

1. メソッド呼び出し

const user = {
  name: '太郎',
  greet() {
    console.log(this.name);  // this = user
  }
};

user.greet();  // '太郎'
// user.greet() → thisはuser

2. 関数呼び出し（注意！）

function showThis() {
  console.log(this);
}

showThis();  // window（ブラウザ）/ undefined（strictモード）
// 誰も呼んでいないので、thisはグローバルか未定義

3. コンストラクタ（new）

class User {
  constructor(name) {
    this.name = name;  // this = 新しいインスタンス
  }
}

const taro = new User('太郎');
// new User() → thisは新しく作られるオブジェクト

4. アロー関数（重要！）

const user = {
  name: '太郎',
  greet: () => {
    console.log(this.name);  // undefined！
  }
};

user.greet();
// アロー関数は「自分のthis」を持たない
// 外側のthis（この場合window）を使う
🔴 超重要：アロー関数のthis

アロー関数はthisを持たない。
定義された場所の外側のthisをそのまま使います。

よくある問題：thisが消える

❌ thisが消える
const user = {
  name: '太郎',
  greet() {
    setTimeout(function() {
      console.log(this.name);
    }, 1000);
  }
};

user.greet();
// undefined（thisがwindowになる）
⭕ アロー関数で解決
const user = {
  name: '太郎',
  greet() {
    setTimeout(() => {
      console.log(this.name);
    }, 1000);
  }
};

user.greet();
// '太郎'（アロー関数は外側のthisを使う）

thisを固定する方法

const user = {
  name: '太郎',
  greet() {
    console.log(this.name);
  }
};

// bind: thisを固定した新しい関数を返す
const boundGreet = user.greet.bind(user);
boundGreet();  // '太郎'

// call: thisを指定して即実行
user.greet.call({ name: '花子' });  // '花子'

// apply: callと同じだが、引数を配列で渡す
user.greet.apply({ name: '花子' });  // '花子'

まとめ表

呼び出し方 thisの値
obj.method() obj
func() window / undefined
new Class() 新しいインスタンス
() => {} 外側のthis（固定）
func.bind(x)() x（固定）

クイズ1：アロー関数のthisの特徴は？

解説：アロー関数は自分のthisを持たないため、 定義された場所の外側のthisをそのまま使います。 これを「レキシカルthis」と呼びます。

クイズ2：このuser.greet()の出力は？ 

const user = {
  name: '太郎',
  greet() {
    console.log(this.name);
  }
};
user.greet();
解説：user.greet()のように オブジェクト.メソッド()で呼ぶと、 thisはそのオブジェクト（user）を指します。

クイズ3：このコードの出力は？ 

const user = {
  name: '太郎',
  greet: () => {
    console.log(this.name);
  }
};
user.greet();
解説：アロー関数は外側のthisを使います。 このコードではオブジェクトリテラルの外側はグローバルスコープなので、 thisはwindow（strictモードではundefined）を指し、 this.nameはundefinedになります。
📝 まとめ
  • thisは呼び出し方で変わる
  • obj.method() → thisはobj
  • アロー関数 → 外側のthisを使う（固定）
  • コールバックではアロー関数が便利
  • bind/call/applyでthisを固定できる
