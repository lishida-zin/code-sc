DOM = HTMLをJavaScriptで操作するための仕組み

HTMLはただの「テキストファイル」です。

ブラウザがHTMLを読み込むと、DOMツリーという構造に変換します。

JavaScriptはこのDOMツリーを操作することで、ページを動的に変更できます。

🌳 DOMツリーのイメージ 
HTML:
<html>
  <body>
    <h1>タイトル</h1>
    <p>本文</p>
  </body>
</html>

DOMツリー:
document
  └─ html
       └─ body
            ├─ h1
            │    └─ "タイトル"
            └─ p
                 └─ "本文"

なぜ「ツリー」と呼ぶのか

HTMLの要素は親子関係を持っています。

  • <body>は<h1>の親（parent）
  • <h1>は<body>の子（child）
  • <h1>と<p>は兄弟（sibling）

この構造が木の枝分かれに似ているので「ツリー」と呼びます。

documentオブジェクト

JavaScriptからDOMにアクセスするための入り口がdocumentです。 

// documentオブジェクト
document              // DOMツリー全体
document.body         // <body>要素
document.head         // <head>要素
document.title        // <title>の中身

// 確認してみよう（ブラウザのコンソールで）
console.log(document.title);

テキストを書き換える、要素を追加・削除する、スタイルを変える...etc

要素を操作する前に「取得」する

DOM操作の第一歩は、操作したい要素を取得することです。

querySelector（推奨）

CSSセレクタで要素を取得する現代的な方法です。 

// IDで取得
const header = document.querySelector('#header');

// クラスで取得（最初の1つ）
const btn = document.querySelector('.btn');

// タグで取得（最初の1つ）
const h1 = document.querySelector('h1');

// 複雑なセレクタもOK
const item = document.querySelector('nav .menu-item:first-child');

querySelectorAll（複数取得）

// マッチするすべての要素を取得
const buttons = document.querySelectorAll('.btn');

// NodeListが返る（配列に似たもの）
buttons.length;    // 要素の数
buttons[0];        // 最初の要素

// ループ処理
buttons.forEach(btn => {
  console.log(btn.textContent);
});

getElementById（古い方法）

// IDで取得（#は不要）
const header = document.getElementById('header');

// これは querySelector と同じ結果
const header2 = document.querySelector('#header');
⚠️ レビューで指摘すべきポイント

getElementByIdは動作しますが、
querySelectorで統一する方がコードの一貫性が保てます。

❌ 混在 
getElementById('header')
querySelector('.nav')
getElementsByClassName('btn')
⭕ 統一 
querySelector('#header')
querySelector('.nav')
querySelectorAll('.btn')

要素が見つからない場合

const element = document.querySelector('.not-exist');
console.log(element);  // null

// そのままプロパティにアクセスするとエラー
element.textContent;   // Error: Cannot read property of null

// 安全にアクセス
if (element) {
  element.textContent = '新しいテキスト';
}

// または オプショナルチェーン
element?.textContent;  // undefined（エラーにならない）

テキストの変更

const el = document.querySelector('#message');

// テキストを取得
console.log(el.textContent);

// テキストを変更
el.textContent = '新しいメッセージ';

textContent vs innerHTML

🔥 最重要：XSS脆弱性

innerHTMLにユーザー入力を直接渡すと、
XSS（クロスサイトスクリプティング）攻撃が可能になります。

❌ 危険（XSS脆弱性） 
// ユーザー入力をそのまま使う
const userInput = '<script>alert("攻撃")</script>';
el.innerHTML = userInput;
// → スクリプトが実行される！
⭕ 安全 
// textContentを使う
const userInput = '<script>alert("攻撃")</script>';
el.textContent = userInput;
// → 文字列として表示される
💡 ルール
  • ユーザー入力 → textContentを使う
  • 自分で書いたHTML → innerHTMLでもOK
  • 迷ったらtextContentを使う

クラスの操作（classList）

const el = document.querySelector('.box');

// クラスを追加
el.classList.add('active');

// クラスを削除
el.classList.remove('active');

// クラスの有無を切り替え
el.classList.toggle('active');

// クラスを持っているか確認
el.classList.contains('active');  // true/false

属性の操作

const link = document.querySelector('a');

// 属性を取得
link.getAttribute('href');

// 属性を設定
link.setAttribute('href', 'https://example.com');

// 属性を削除
link.removeAttribute('target');

// data属性
el.dataset.userId;        // data-user-id の値
el.dataset.userId = '123'; // 設定

スタイルの操作

const el = document.querySelector('.box');

// インラインスタイルを設定
el.style.color = 'red';
el.style.backgroundColor = 'blue';  // キャメルケース

// 複数のスタイルを一度に
el.style.cssText = 'color: red; background: blue;';
⚠️ ベストプラクティス

スタイルの変更はclassListでクラスを付け替える方が推奨。
CSSでスタイルを定義し、JSではクラスの追加/削除だけ行う。 

// ❌ JSでスタイル直接変更
el.style.color = 'red';
el.style.fontWeight = 'bold';

// ⭕ クラスで切り替え
el.classList.add('highlight');
// CSS: .highlight { color: red; font-weight: bold; }
🔍 コードレビューの観点
  • innerHTML + ユーザー入力 = XSSリスク：ユーザー由来のデータは必ずtextContentで挿入する
  • イベントリスナーのメモリリーク：SPA等で要素を削除する際、removeEventListenerで不要なリスナーを解除しているか
  • querySelector vs getElementById：プロジェクト内でAPIを統一し、querySelector系に揃えるのが推奨

イベント = 「何かが起きた」という通知

ユーザーがボタンをクリックした、キーを押した、ページが読み込まれた...

これらはすべてイベントです。

JavaScriptは「イベントが起きたら何かする」という形で動作を定義します。

addEventListener

const button = document.querySelector('#myButton');

// クリックされたら関数を実行
button.addEventListener('click', () => {
  console.log('クリックされた！');
});

// 関数を別で定義してもOK
function handleClick() {
  console.log('クリックされた！');
}
button.addEventListener('click', handleClick);

よく使うイベント

イベント 発生タイミング
click クリックした時
submit フォーム送信時
keydown キーを押した時
input 入力値が変わった時
change 値が確定した時
focus フォーカスが当たった時
blur フォーカスが外れた時
load 読み込み完了時

イベントオブジェクト

イベントが発生すると、詳細情報を持ったイベントオブジェクトが渡されます。 

button.addEventListener('click', (event) => {
  // イベントオブジェクトを受け取る
  console.log(event.type);      // "click"
  console.log(event.target);    // クリックされた要素
  console.log(event.currentTarget); // リスナーが付いた要素
});

// キーイベントの例
input.addEventListener('keydown', (event) => {
  console.log(event.key);       // 押されたキー（"Enter"など）
  console.log(event.code);      // キーコード
});

デフォルト動作のキャンセル

// リンクのデフォルト動作（ページ遷移）を止める
link.addEventListener('click', (event) => {
  event.preventDefault();
  console.log('ページ遷移せずに処理');
});

// フォームのデフォルト動作（送信）を止める
form.addEventListener('submit', (event) => {
  event.preventDefault();
  // 独自のバリデーションや送信処理
});

イベントは「伝播」する

子要素で発生したイベントは、親要素にも伝わります。 

<div id="parent">
  <button id="child">クリック</button>
</div>

<script>
  document.querySelector('#parent').addEventListener('click', () => {
    console.log('親がクリックされた');
  });

  document.querySelector('#child').addEventListener('click', () => {
    console.log('子がクリックされた');
  });

  // ボタンをクリックすると:
  // "子がクリックされた"
  // "親がクリックされた"  ← 親にも伝わる！
</script>

バブリングを止める

child.addEventListener('click', (event) => {
  event.stopPropagation();  // 親に伝わらなくなる
  console.log('子がクリックされた');
});

イベント委譲（重要！）

多くの要素にイベントを付ける場合、親要素で一括管理すると効率的です。

❌ 非効率（各要素にリスナー） 
// 100個のボタンに100個のリスナー
buttons.forEach(btn => {
  btn.addEventListener('click', () => {
    console.log('クリック');
  });
});
// → メモリ消費大
⭕ 効率的（イベント委譲） 
// 親要素に1つだけリスナー
container.addEventListener('click', (e) => {
  if (e.target.matches('.btn')) {
    console.log('クリック');
  }
});
// → メモリ節約
💡 イベント委譲のメリット
  • メモリ効率: リスナーが1つで済む
  • 動的要素対応: 後から追加された要素にも自動で対応
  • コード簡潔化: 管理が楽になる

event.target と event.currentTarget

container.addEventListener('click', (e) => {
  console.log(e.target);        // 実際にクリックされた要素
  console.log(e.currentTarget); // リスナーが付いている要素（container）
});

フォーム要素の値を取得

// テキスト入力
const input = document.querySelector('#name');
console.log(input.value);  // 入力された値

// セレクトボックス
const select = document.querySelector('#country');
console.log(select.value);  // 選択された値

// チェックボックス
const checkbox = document.querySelector('#agree');
console.log(checkbox.checked);  // true/false

// ラジオボタン
const radios = document.querySelectorAll('[name="gender"]');
radios.forEach(radio => {
  if (radio.checked) {
    console.log(radio.value);  // 選択された値
  }
});

リアルタイムバリデーション

const emailInput = document.querySelector('#email');
const errorMsg = document.querySelector('#email-error');

emailInput.addEventListener('input', () => {
  const email = emailInput.value;

  // メール形式チェック
  const isValid = email.includes('@') && email.includes('.');

  if (!isValid && email.length > 0) {
    errorMsg.textContent = 'メールアドレスの形式が不正です';
    emailInput.classList.add('error');
  } else {
    errorMsg.textContent = '';
    emailInput.classList.remove('error');
  }
});

フォーム送信の制御

const form = document.querySelector('#myForm');

form.addEventListener('submit', (event) => {
  event.preventDefault();  // デフォルトの送信を止める

  // バリデーション
  const name = form.querySelector('#name').value;
  const email = form.querySelector('#email').value;

  if (!name || !email) {
    alert('すべての項目を入力してください');
    return;
  }

  // 送信処理
  console.log('送信:', { name, email });

  // APIに送信する場合
  // fetch('/api/submit', { method: 'POST', body: ... });
});

FormData API

form.addEventListener('submit', (event) => {
  event.preventDefault();

  // FormDataで一括取得
  const formData = new FormData(form);

  // 値を取り出す
  console.log(formData.get('name'));
  console.log(formData.get('email'));

  // オブジェクトに変換
  const data = Object.fromEntries(formData);
  console.log(data);  // { name: "...", email: "..." }
});
⚠️ セキュリティ注意

クライアント側のバリデーションだけでは不十分です。
悪意あるユーザーはJavaScriptを無効にできます。
必ずサーバー側でも検証してください。
