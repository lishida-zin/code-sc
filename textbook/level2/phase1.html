Webページに「動き」を加える言語

HTMLは「骨組み」、CSSは「見た目」でしたね。

では、JavaScriptは何でしょう？

JavaScriptは「動き」を担当します。

🏠 家に例えると
  • HTML = 柱、壁、窓（構造）
  • CSS = 壁紙、カーテン、照明（装飾）
  • JavaScript = 電気系統、センサー、自動ドア（動き）

スイッチを押すと電気がつく、人が近づくとドアが開く。
そういう「反応」や「動き」がJavaScriptの役目です。

JavaScriptでできること

実際にWebサイトでよく見る動きを挙げてみましょう。

  • ボタンをクリックしたら何かが起きる（メニューが開く、画像が変わる）
  • 入力をリアルタイムでチェック（メールアドレスの形式確認）
  • データを取ってきて表示（天気予報、ニュース記事）
  • アニメーション（スライドショー、スクロール連動）
  • ゲーム（ブラウザで動くゲーム）

どこで動くの？（実行環境）

JavaScriptは主に2つの場所で動きます。

ブラウザ（フロントエンド）

あなたのパソコンやスマホのブラウザで動きます。

  • Chrome、Firefox、Safari など
  • ユーザーの目に見える部分を担当
  • ボタンクリック、アニメーションなど
サーバー（バックエンド）

Node.jsを使うと、サーバー側でも動きます。

  • データベースとのやり取り
  • APIの作成
  • ユーザーには見えない裏側の処理
💡 このレベルでは

まずはブラウザで動くJavaScriptを学びます。
サーバー側（Node.js）はLevel 4で学習します。

JavaScriptとJavaは別物！

⚠️ よくある誤解

「JavaScript」と「Java」は全くの別物です。

名前が似ているのは歴史的な理由（マーケティング）で、
文法も用途も違います。混同しないようにしましょう。

2026年、なぜJavaScriptが重要？

AIがコードを書く時代になりました。

でも、AIが書いたJavaScriptコードには問題が潜んでいることがあります。

  • 非同期処理のミス（データが取得される前に使おうとする）
  • 型の変換バグ（"1" + 1 が "11" になる）
  • セキュリティの穴（XSS攻撃が可能なコード）

これらを見抜ける力が、シニアエンジニアには必要です。

これがLevel 2で身につける力です。

変数と定数

📚 このページで学ぶこと
  • 変数とは何か（データを入れる箱）
  • let、const、varの違い
  • なぜvarを使わないのか（2026年のベストプラクティス）

変数 = データを入れる「箱」

プログラミングでは、データを一時的に保存しておく必要があります。

その「保存場所」が変数です。

📦 イメージ

変数は「ラベル付きの箱」と考えてください。

  • 箱に名前（ラベル）をつける → userName
  • 箱の中にデータを入れる → "太郎"
  • 後で箱の中身を取り出せる → userNameで"太郎"を参照

3つの宣言方法

JavaScriptで変数を作る方法は3つあります。 

// 1. const: 再代入できない（定数）
const TAX_RATE = 0.1;

// 2. let: 再代入できる（変数）
let count = 0;
count = 1;  // OK

// 3. var: 古い書き方（使わない）
var oldStyle = "避けるべき";

const と let の使い分け

⭕ const（基本はこれ） 
// 変わらない値
const PI = 3.14159;
const userName = "太郎";
const config = { debug: true };

一度入れたら変えないものに使う

🔄 let（必要な時だけ） 
// 変わる値
let count = 0;
count++;  // 1になる

let total = 0;
total = total + 100;

後から値を変えるものに使う

💡 ベストプラクティス

まず const で書く。
再代入が必要になったら let に変える。
この順番で考えると、バグが減ります。

なぜ var を使わないのか

varには危険な特徴があります。

⚠️ varの問題点

問題1: 同じ名前で再宣言できてしまう

var name = "太郎";
var name = "次郎";  // エラーにならない（上書きされる）

// let/const なら
let name = "太郎";
let name = "次郎";  // エラー！（気づける）

問題2: スコープが広すぎる（関数スコープ）

if (true) {
  var leaked = "漏れる";  // ブロックの外でも使える
  let safe = "安全";      // ブロックの中だけ
}
console.log(leaked);  // "漏れる"（意図しない動作）
console.log(safe);    // エラー（正しい動作）

2015年にlet/constが導入されてから、varを使う理由はなくなりました。

🔍 レビューで指摘すべきポイント

AIが書いたコードにvarがあったら、
「let または const を使うべき」と指摘しましょう。

命名規則

変数名の付け方にはルールがあります。

⭕ 良い命名 
// キャメルケース（推奨）
const userName = "太郎";
const totalPrice = 1000;
const isLoggedIn = true;

// 定数は大文字+アンダースコア
const MAX_RETRY = 3;
const API_URL = "/api";
❌ 悪い命名 
// 意味不明
const x = "太郎";
const a = 1000;
const flag = true;

// 予約語と紛らわしい
const class = "A";  // エラー
const for = 1;      // エラー
📝 キャメルケースとは

camelCase: 最初の単語は小文字、2語目以降の先頭を大文字にする書き方。
ラクダ（camel）のコブのように見えることから名付けられました。
例: userName, totalPrice, isLoggedIn

データ型

📚 このページで学ぶこと
  • プリミティブ型とは
  • 参照型とは
  • typeof演算子での型確認

データには「型」がある

JavaScriptで扱うデータには、それぞれ「型」があります。

型を理解することで、バグの原因が見えるようになります。

プリミティブ型（基本型）

最も基本的なデータの種類です。

型 説明 例
string 文字列 "こんにちは", 'Hello'
number 数値（整数・小数） 42, 3.14
boolean 真偽値 true, false
undefined 未定義 undefined
null 空（意図的に空） null
bigint 巨大整数 9007199254740991n
symbol 一意な識別子 Symbol("id")

参照型（オブジェクト型）

複数のデータをまとめて扱う型です。 

// オブジェクト
const user = {
  name: "太郎",
  age: 25
};

// 配列
const numbers = [1, 2, 3, 4, 5];

// 関数
const greet = function() {
  return "こんにちは";
};
⚠️ プリミティブ型と参照型の違い

プリミティブ型: 値そのものがコピーされる

let a = 10;
let b = a;  // 10がコピーされる
b = 20;
console.log(a);  // 10（変わらない）

参照型: 参照（住所）がコピーされる

const obj1 = { name: "太郎" };
const obj2 = obj1;  // 参照がコピーされる
obj2.name = "次郎";
console.log(obj1.name);  // "次郎"（変わってしまう！）

typeof で型を確認

typeof演算子を使うと、データの型を確認できます。 

typeof "hello"     // "string"
typeof 42          // "number"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof null        // "object" ← 歴史的バグ！
typeof {}          // "object"
typeof []          // "object" ← 配列もobject
typeof function(){} // "function"
🐛 有名なバグ

typeof null が "object" を返すのは、
JavaScriptの歴史的なバグです。
今さら修正すると既存のコードが壊れるので、そのままになっています。

配列かどうかを確認する方法

const arr = [1, 2, 3];

// typeofでは判別できない
typeof arr;  // "object"

// Array.isArray()を使う
Array.isArray(arr);  // true
Array.isArray({});   // false

console.log(original.count);

演算子

📚 このページで学ぶこと
  • 算術演算子、代入演算子
  • 比較演算子（== と === の違い）
  • 論理演算子

算術演算子

計算に使う演算子です。 

const a = 10;
const b = 3;

a + b   // 13（加算）
a - b   // 7（減算）
a * b   // 30（乗算）
a / b   // 3.333...（除算）
a % b   // 1（剰余・余り）
a ** b  // 1000（べき乗、10の3乗）
⚠️ 文字列との足し算に注意 
// 数値 + 数値 = 数値
10 + 5    // 15

// 文字列 + 文字列 = 結合
"Hello" + "World"  // "HelloWorld"

// 数値 + 文字列 = 文字列として結合！
10 + "5"  // "105" ← バグの温床！
"5" + 10  // "510"

代入演算子

let x = 10;

x += 5;   // x = x + 5  → 15
x -= 3;   // x = x - 3  → 12
x *= 2;   // x = x * 2  → 24
x /= 4;   // x = x / 4  → 6

// インクリメント・デクリメント
x++;      // x = x + 1
x--;      // x = x - 1

比較演算子（最重要！）

🔥 == と === の違い

これは最もバグを生みやすいポイントです。

❌ ==（等価演算子） 
// 型変換してから比較（危険）
1 == "1"     // true
0 == false   // true
null == undefined  // true
"" == 0      // true

型が違っても true になる

⭕ ===（厳密等価演算子） 
// 型も含めて比較（安全）
1 === "1"    // false
0 === false  // false
null === undefined  // false
"" === 0     // false

型が違えば false になる

💡 ベストプラクティス

常に === を使う。
== を使う理由がある場面は、ほぼありません。
AIが書いたコードに == があったら、即座に指摘しましょう。

その他の比較演算子

5 > 3    // true（より大きい）
5 < 3    // false（より小さい）
5 >= 5   // true（以上）
5 <= 4   // false（以下）
5 !== 3  // true（厳密不等価）

論理演算子

// AND: 両方 true なら true
true && true   // true
true && false  // false

// OR: どちらかが true なら true
true || false  // true
false || false // false

// NOT: 反転
!true   // false
!false  // true

短絡評価（ショートサーキット）

// AND: 左が false なら右は評価されない
false && doSomething()  // doSomething()は実行されない

// OR: 左が true なら右は評価されない
true || doSomething()   // doSomething()は実行されない

// よく使うパターン
const name = user.name || "名無し";  // nameがなければ"名無し"
const result = isReady && execute();  // isReadyがtrueの時だけ実行
🔍 コードレビューの観点
  • == の使用：暗黙の型変換に依存しており予測困難なバグの原因になる。===に統一すべき
  • 文字列 + 数値の結合："5" + 3 が "53" になる暗黙変換を見逃さない
  • Falsy値の罠：0, "", null, undefined, NaN が全てfalseに変換される点に注意

条件分岐: if文

条件によって処理を分ける基本的な方法です。 

const age = 20;

if (age >= 20) {
  console.log("成人です");
} else if (age >= 13) {
  console.log("ティーンエイジャーです");
} else {
  console.log("子どもです");
}

三項演算子（条件演算子）

// if-else を1行で書ける
const message = age >= 20 ? "成人" : "未成年";

// 読みやすさのために分けることも
const status = isLoggedIn
  ? "ログイン中"
  : "ログアウト中";
⚠️ 三項演算子の注意点

ネストすると読みにくくなるので避けましょう。 

// ❌ 読みにくい
const result = a ? b ? c : d : e;

// ⭕ if-else で書く
let result;
if (a) {
  result = b ? c : d;
} else {
  result = e;
}

条件分岐: switch文

値によって処理を分ける場合に使います。 

const fruit = "apple";

switch (fruit) {
  case "apple":
    console.log("りんご");
    break;
  case "banana":
    console.log("バナナ");
    break;
  case "orange":
    console.log("オレンジ");
    break;
  default:
    console.log("不明な果物");
}
⚠️ break を忘れると 
// break がないと次の case も実行される（フォールスルー）
switch (num) {
  case 1:
    console.log("1です");
    // break がない！
  case 2:
    console.log("2です");  // num=1 でもここが実行される
    break;
}

ループ: for文

// 基本形
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}

// 配列をループ（インデックスが必要な場合）
const items = ["a", "b", "c"];
for (let i = 0; i < items.length; i++) {
  console.log(i, items[i]);
}

ループ: for...of（推奨）

配列の要素を順番に取り出す、現代的な書き方です。 

const items = ["りんご", "バナナ", "オレンジ"];

// ⭕ for...of（シンプル）
for (const item of items) {
  console.log(item);
}

// インデックスも必要なら entries()
for (const [index, item] of items.entries()) {
  console.log(index, item);
}

ループ: while文

let count = 0;

while (count < 3) {
  console.log(count);
  count++;
}
// 0, 1, 2
⚠️ 無限ループに注意 
// ❌ 危険：countが増えないので永遠に終わらない
while (count < 3) {
  console.log(count);
  // count++ を忘れている！
}

break と continue

// break: ループを抜ける
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i);  // 0, 1, 2, 3, 4
}

// continue: 次のループへスキップ
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i);  // 0, 1, 3, 4（2がスキップ）
}

関数

📚 このページで学ぶこと

関数 = 処理をまとめたもの

同じ処理を何度も書くのは面倒ですし、ミスの元です。

関数を使えば、処理を一箇所にまとめて再利用できます。

🏭 イメージ

関数は「工場」のようなものです。
材料（引数）を入れると、製品（戻り値）が出てきます。

関数の3つの書き方

1. 関数宣言

// 伝統的な書き方
function greet(name) {
  return `こんにちは、${name}さん`;
}

greet("太郎");  // "こんにちは、太郎さん"

2. 関数式

// 変数に関数を代入
const greet = function(name) {
  return `こんにちは、${name}さん`;
};

greet("太郎");  // "こんにちは、太郎さん"

3. アロー関数（現代的）

// ES6から追加された書き方
const greet = (name) => {
  return `こんにちは、${name}さん`;
};

// 1行で書ける場合は省略できる
const greet = (name) => `こんにちは、${name}さん`;

// 引数が1つなら括弧も省略可
const greet = name => `こんにちは、${name}さん`;
💡 2026年のベストプラクティス

アロー関数を基本に使う。
ただし、thisの挙動が異なるため、
オブジェクトのメソッドでは関数宣言を使う場面もあります。

引数とデフォルト値

// デフォルト値を設定できる
const greet = (name = "ゲスト") => {
  return `こんにちは、${name}さん`;
};

greet();        // "こんにちは、ゲストさん"
greet("太郎");  // "こんにちは、太郎さん"

戻り値

// return で値を返す
const add = (a, b) => {
  return a + b;
};

const result = add(3, 5);  // 8

// return がないと undefined
const noReturn = () => {
  console.log("処理だけ");
};
const result2 = noReturn();  // undefined

関数宣言 vs 関数式の違い

⚠️ ホイスティング（巻き上げ）

関数宣言は、宣言前に呼び出せる（ホイスティング）

greet();  // OK: "こんにちは"

function greet() {
  return "こんにちは";
}

関数式・アロー関数は、宣言前に呼び出せない

greet();  // エラー！

const greet = () => "こんにちは";

スコープ

📚 このページで学ぶこと
  • スコープとは何か
  • グローバル、関数、ブロックスコープ
  • 変数の「見える範囲」を理解する

スコープ = 変数が見える範囲

変数には「見える範囲」があります。これをスコープと呼びます。

🏠 イメージ

スコープは「部屋」のようなものです。
部屋の中で宣言した変数は、その部屋の中でしか使えません。
ただし、外の部屋の変数は中から見えます。

3種類のスコープ

1. グローバルスコープ

// どこからでもアクセスできる
const globalVar = "グローバル";

function test() {
  console.log(globalVar);  // OK: "グローバル"
}

console.log(globalVar);    // OK: "グローバル"

2. 関数スコープ

function test() {
  const localVar = "関数内";
  console.log(localVar);  // OK: "関数内"
}

test();
console.log(localVar);  // エラー！関数の外からは見えない

3. ブロックスコープ（let/const）

if (true) {
  const blockVar = "ブロック内";
  console.log(blockVar);  // OK: "ブロック内"
}

console.log(blockVar);  // エラー！ブロックの外からは見えない

var の問題（復習）

⚠️ varはブロックスコープを無視する 
if (true) {
  var leaked = "漏れる";
  let safe = "安全";
}

console.log(leaked);  // "漏れる"（ブロックの外に漏れる）
console.log(safe);    // エラー（正しくブロック内に留まる）

これがvarを使わない理由の一つです。

スコープチェーン

内側のスコープから外側のスコープの変数にアクセスできます。 

const outer = "外";

function test() {
  const middle = "中";

  function inner() {
    const innerVar = "内";
    console.log(innerVar);  // "内"
    console.log(middle);    // "中"（外側の関数の変数）
    console.log(outer);     // "外"（グローバル変数）
  }

  inner();
}

test();
💡 覚えておくこと
  • 内から外は見える
  • 外から内は見えない
🔍 コードレビューの観点
  • varのスコープ漏れ：forループ内のvarがブロック外に漏れていないか確認

配列

📚 このページで学ぶこと
  • 配列とは何か
  • よく使う配列メソッド（map, filter, reduce）
  • 配列を読み解く力

配列 = 複数のデータをまとめる

// 配列の作成
const fruits = ["りんご", "バナナ", "オレンジ"];

// 要素へのアクセス（インデックスは0から）
fruits[0];  // "りんご"
fruits[1];  // "バナナ"
fruits[2];  // "オレンジ"

// 配列の長さ
fruits.length;  // 3

配列の操作

const arr = [1, 2, 3];

// 末尾に追加
arr.push(4);       // [1, 2, 3, 4]

// 末尾から削除
arr.pop();         // [1, 2, 3]

// 先頭に追加
arr.unshift(0);    // [0, 1, 2, 3]

// 先頭から削除
arr.shift();       // [1, 2, 3]

重要なメソッド: map

配列の各要素を変換して新しい配列を作る。 

const numbers = [1, 2, 3, 4, 5];

// 各要素を2倍にする
const doubled = numbers.map(n => n * 2);
// [2, 4, 6, 8, 10]

// 元の配列は変わらない（非破壊的）
console.log(numbers);  // [1, 2, 3, 4, 5]

重要なメソッド: filter

条件に合う要素だけを抽出して新しい配列を作る。 

const numbers = [1, 2, 3, 4, 5];

// 偶数だけ抽出
const evens = numbers.filter(n => n % 2 === 0);
// [2, 4]

重要なメソッド: reduce

配列を1つの値にまとめる。 

const numbers = [1, 2, 3, 4, 5];

// 合計を求める
const sum = numbers.reduce((acc, n) => acc + n, 0);
// 15

// acc: 累積値（初期値は0）
// n: 現在の要素

メソッドチェーン

メソッドを繋げて書くことができます。 

const users = [
  { name: "太郎", age: 25 },
  { name: "花子", age: 17 },
  { name: "次郎", age: 30 }
];

// 20歳以上のユーザー名だけを取得
const adultNames = users
  .filter(user => user.age >= 20)
  .map(user => user.name);
// ["太郎", "次郎"]
💡 読むコツ

メソッドチェーンは上から順番に読みます。
1. filter で絞り込む → 2. map で変換する
この流れをイメージしましょう。

要素の検索

const numbers = [1, 2, 3, 4, 5];

// 条件に合う最初の要素を見つける
numbers.find(n => n > 3);       // 4

// 条件に合う要素があるか確認
numbers.some(n => n > 3);       // true
numbers.every(n => n > 3);      // false（すべてではない）

// 要素が含まれているか
numbers.includes(3);            // true
🔍 コードレビューの観点
  • ミュータブル操作の危険性：push, splice, sort は元の配列を変更する。意図しない副作用がないか確認
  • 参照の共有：const copy = original は参照コピー。独立コピーには [...arr] や {...obj} を使うべき
  • 配列メソッドの戻り値：forEachはundefinedを返す。値が必要ならmapを使うべき

オブジェクト

📚 このページで学ぶこと
  • オブジェクトとは何か
  • プロパティへのアクセス方法
  • オブジェクトの操作

オブジェクト = 関連するデータをまとめる

配列は「順番のあるリスト」でした。

オブジェクトは「名前付きのデータの集まり」です。 

// ユーザー情報をまとめる
const user = {
  name: "太郎",
  age: 25,
  email: "taro@example.com",
  isAdmin: false
};
📁 イメージ

オブジェクトは「ラベル付きの引き出し」です。
「名前」の引き出しを開けると「太郎」が入っている、
「年齢」の引き出しを開けると「25」が入っている。

プロパティへのアクセス

const user = {
  name: "太郎",
  age: 25
};

// ドット記法（基本）
user.name;      // "太郎"
user.age;       // 25

// ブラケット記法（変数で指定する場合）
const key = "name";
user[key];      // "太郎"

// 存在しないプロパティ
user.address;   // undefined

プロパティの追加・変更・削除

const user = { name: "太郎" };

// 追加
user.age = 25;
// { name: "太郎", age: 25 }

// 変更
user.name = "次郎";
// { name: "次郎", age: 25 }

// 削除
delete user.age;
// { name: "次郎" }
⚠️ constでも中身は変えられる 
const user = { name: "太郎" };

// ❌ これはエラー（再代入）
user = { name: "次郎" };

// ⭕ これはOK（中身の変更）
user.name = "次郎";

constは「変数自体の再代入を禁止」するだけで、
オブジェクトの中身を変えることは許可されています。

オブジェクトの便利な操作

const user = { name: "太郎", age: 25 };

// キーの一覧
Object.keys(user);    // ["name", "age"]

// 値の一覧
Object.values(user);  // ["太郎", 25]

// キーと値のペア
Object.entries(user); // [["name", "太郎"], ["age", 25]]

// プロパティの存在確認
"name" in user;       // true
"address" in user;    // false

オブジェクトのループ

const user = { name: "太郎", age: 25 };

// for...in（キーでループ）
for (const key in user) {
  console.log(key, user[key]);
}
// "name" "太郎"
// "age" 25

// Object.entries + for...of（推奨）
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}

ネストしたオブジェクト

const user = {
  name: "太郎",
  address: {
    city: "東京",
    zip: "100-0001"
  }
};

// ネストにアクセス
user.address.city;  // "東京"

// オプショナルチェーン（安全なアクセス）
user.address?.city;   // "東京"
user.company?.name;   // undefined（エラーにならない）
💡 オプショナルチェーン ?.

?.を使うと、途中がnullやundefinedでも
エラーにならずにundefinedを返します。
APIからのデータなど、存在しない可能性がある場合に便利です。
