### SVG図解のスタイルガイド

```
【色使い】
- 良い例（グリーン系）: #22c55e, #16a34a
- 悪い例（レッド系）: #ef4444, #dc2626
- 中立（ブルー系）: #3b82f6, #2563eb
- 背景: #f8fafc（ライト）/ #1e293b（ダーク対応）

【フォント】
- 日本語: "UD デジタル 教科書体", sans-serif
- コード: "Fira Code", monospace

【サイズ】
- 最小幅: 300px（モバイル対応）
- 最大幅: 800px
- 高さ: コンテンツに応じて可変

【アクセシビリティ】
- <title>タグで図の説明を追加
- 色だけに依存しない（アイコン/パターンも併用）
- aria-label属性を設定
```
