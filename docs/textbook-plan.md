# いしだ式エンジニアへの道 - HTML教科書プラン

## 概要

**ファイル名**: `textbook/ishida-style-engineer.html`
**コンセプト**: 1つのHTMLファイルに全コンテンツを集約し、ナビゲーションメニューで管理

## 要件

1. **単一HTMLファイル** - 管理しやすい構造
2. **Phaseごとに順次作成** - 内容の充実を優先
3. **各Phase 5ページ以上** - 詳細な内容
4. **難所は大幅増量** - つまずきポイントを手厚くカバー
5. **忘却曲線対応** - 復習システム組み込み
6. **インタラクティブ** - クイズ、アコーディオン、進捗表示

## 実装済み機能

### 1. ナビゲーションメニュー
- 固定サイドバー
- 現在位置ハイライト
- Level/Phase折りたたみ可能
- 進捗表示（完了マーク）

### 2. 各セクションの構成
```
1. 導入（たとえ話）
2. 語源・由来
3. 概念説明
4. コード例（良い例 / 悪い例）
5. 開発思想（WHY → HOW → EFFECT）
6. 確認クイズ
7. レビュー観点
8. まとめ
```

### 3. インタラクティブ要素
- `<details>/<summary>` - アコーディオン
- チェックボックス/ラジオボタン - クイズ
- `<progress>` - 進捗バー
- localStorage - 進捗保存

### 4. デザイン
- ダークモード
- レスポンシブ対応
- カード形式のコンテンツ
- バッジ・成果表示
