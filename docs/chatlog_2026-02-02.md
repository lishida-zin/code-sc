## Lesson 01: HTMLとは？ - Webページの骨組み

### 🤔 そもそも「コードを読む」とは？

Webサイトを見るとき、あなたが見ているのは **完成品（料理）** です。
HTMLは、その **レシピ（設計図）** にあたります。

```
あなたが見ているもの → キレイなWebページ
裏側にあるもの      → HTMLコード（テキストファイル）
```

### 🏗️ HTMLの正体

**HTML = HyperText Markup Language（ハイパーテキスト・マークアップ・ランゲージ）**

難しそう？分解すると簡単です：

| 単語 | 意味 | 例え |
|------|------|------|
| HyperText | リンクでつながるテキスト | 本の「○○ページを見よ」みたいなもの |
| Markup | 印をつける | 「ここは見出し」「ここは段落」と付箋を貼る感じ |
| Language | 言語 | ブラウザが理解できる言葉 |

### 💡 核心ポイント

**HTMLは「意味」を伝える言語です。**

「この文字は見出しです」「これはリンクです」「これは画像です」と、ブラウザに **役割** を教えています。

見た目を整えるのは **CSS の仕事**（後で学びます）。
