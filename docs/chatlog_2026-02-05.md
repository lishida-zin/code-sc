`★ Insight ─────────────────────────────────────`
`git pull --rebase` はリモートの新しい変更を取り込みつつ、自分のコミットをその上に積み直します。通常の `git pull`（merge）だと余分なマージコミットが増えますが、rebaseだと履歴がきれいな一直線になります。チーム開発ではrebase派 vs merge派で議論になることもありますが、**まだプッシュしていないローカルコミット**に対してのrebaseは安全です。
`─────────────────────────────────────────────────`
